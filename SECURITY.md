# Security Policy

BrightKeys installs a low-level keyboard hook to detect its hotkeys. The hook only compares each key
against your configured bindings. Nothing is logged, stored or sent anywhere, and the app makes no
network connections at all ("Check for updates" just opens the Releases page in your browser).

## Reporting a vulnerability

Please report security issues privately through
[GitHub Security Advisories](https://github.com/tejashwikalptaru/brightkeys/security/advisories/new)
rather than a public issue. You should get a reply within a few days.

Only the latest release receives fixes.
